Make space for what you know.

In about ten minutes you'll have a palace: plain text any file-aware AI can read, in a folder you choose. What you figure out today, your AI picks up tomorrow.

Build your mindspace.

01

Create one room

A room is a named context: a folder with one plain-text memory file (CLAUDE.md works). Your AI reads it at the start of every session there.

Two sentences will do: what is this room for, and what must never be forgotten here?

# Dev Room
This room holds the main product context.
Stack: Next.js 14 / PostgreSQL / Railway.

## Crystals
- yarn dev  ← the start command
- Never push to main without a PR
02

Plant one crystal

A crystal is a fact established once and never re-derived: the thing you keep explaining at the start of every session. Write it in the room's file.

Good crystals are small, specific and stable. "We use pnpm, not npm" is a crystal. "The project is complex" is not.

## Crystals
- Auth token lives in .env.local, not committed
- Component library: shadcn/ui, do not use MUI
- The staging env is at staging.acme.dev (separate API)
03

Seed one garden plant

A garden plant is an open question you grow toward across sessions, not a task.

Keep one file per plant in a garden/ folder next to your rooms.

# Plant: The Right Abstraction
**Planted:** 2026-04-28
**Question:** When does an abstraction
become the wrong one?

## Notes
- Session 1: leaky abstractions are honest
- Session 3: the cost comes when the leak
  becomes load-bearing

The soul layer

Setup asks a few questions about your work and what you're curious about, then your AI offers names for itself, shaped by your answers. Pick one; that is who it becomes.

soul/SOUL.md holds its character and what it has learned about you. The palace keeps facts. The soul keeps perspective.

04

Run your first session

Open a new conversation. Your AI should read the palace files before it speaks.

Start Claude Code in your palace folder and it reads CLAUDE.md on its own. Elsewhere, paste the room file at the top of the conversation.

Close every session the same way. The palace only works if it grows.

## Session close ritual
1. Did anything become ground truth today? → Crystal
2. Did any question deepen? → Water the plant
3. Did the room context change? → Update the room file
4. What does the next session need to know? → Handover
